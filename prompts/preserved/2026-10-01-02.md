The Compose test environment resumes the effect inline on that worker when the main thread is outside a test-clock frame. The worker then recomposes and applies while the main thread is in its own layout pass.

**The rule.**
1. **Production is unchanged:** `DecodedPhoto` decodes on `Dispatchers.IO`, as today. The dispatcher comes from **one** place.
2. **In the unit tests, by default,** the decode runs on a dispatcher that keeps the effect's resumption on the main (test) thread, so no worker thread ever drives a Compose frame. That default applies to **every** Robolectric test, without editing each test class.
3. **A test that needs a real background decode can still ask for one.** -317's `DecodedPhotoGestureTest`, `DecodedPhotoSemanticsTest` and `DecodedPhotoPlaceholderSizeTest` gate the decode on a latch (`GatedBitmapFactoryShadow`, `GatedDecodeSupport`), so they must not deadlock, and they must still put the swap between down and up.
