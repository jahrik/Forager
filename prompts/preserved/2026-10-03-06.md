But when starting navigation mode, the camera should zoom to a set point to focus on the navigating. Right now no camera adjustments other than tilt exist."

## The behaviour, as confirmed

1. Tap Return. The map tilts, faces the walker's direction, **and zooms to street level, showing about two blocks ahead.**
2. Pinch to zoom. The map keeps that zoom and keeps following, for the rest of that navigation.
3. Drag the map away. "Return to Route" appears; tapping it brings back following and facing-up **at the zoom the walker had**, not the set one.
4. Tap Stop. The map eases flat and north-up, as it does now.

So the set zoom is applied **once, when navigation starts**. Not when the facing changes (calibrating, north-up, back to facing-up), and not on "Return to Route". A new navigation (Stop, then Return again) starts at the set zoom again.
